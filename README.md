# 🎮 QuizBlast — Kahoot-style Quiz Game

เกมส์ตอบคำถามแบบ Kahoot ที่เล่นได้ผ่าน Browser โดยไม่ต้องติดตั้งอะไรเพิ่ม

## วิธีเล่น

1. เปิดไฟล์ `index.html` ใน Browser
2. ใส่ชื่อของคุณ
3. กด **เริ่มเล่น** แล้วตอบคำถาม 10 ข้อ
4. ยิ่งตอบเร็ว ยิ่งได้คะแนนมาก!
5. ดูผลและ Leaderboard ตอนท้าย

## ฟีเจอร์

- ⏱️ Timer 20 วินาทีต่อคำถาม
- 🎯 คะแนนตามความเร็วในการตอบ (สูงสุด 1,000 คะแนน/ข้อ)
- 🤖 AI opponents จำลองผู้เล่นคนอื่น
- 🏆 Leaderboard สรุปผลตอนท้าย
- 🎨 UI สไตล์ Kahoot — สีสัน animation ครบ

## โครงสร้างไฟล์

```
kahoot-game/
├── index.html   — โครงสร้าง HTML
├── style.css    — สไตล์และ animation
├── game.js      — ลอจิกเกมส์ + คำถาม
└── README.md
```

## การแก้ไขคำถาม

เปิดไฟล์ `game.js` แล้วแก้ไข array `QUESTIONS` ด้านบนไฟล์:

```js
const QUESTIONS = [
  {
    q: "คำถามของคุณ?",
    choices: ["ตัวเลือก A", "ตัวเลือก B", "ตัวเลือก C", "ตัวเลือก D"],
    answer: 0   // index ของคำตอบที่ถูก (0-3)
  },
  // ...
];
```
